Frontales / portales de cliente (JSP → Angular/React): interfaces de autogestión y portales de cliente construidos sobre tecnologías obsoletas. Modernización incremental módulo a módulo. Hasta el 81% de clientes abandona una aplicación lenta o deficiente — la modernización reduce esa tasa y eleva el NPS por encima del 30%. Mejora del 30-60% en tiempo de respuesta.

Middleware / ESB → microservicios: el ESB que bloquea el time-to-market. Cada integración con un nuevo partner, API de red o servicio digital pasa por un bus que hay que coordinar completo. Migrar a microservicios permite escalar cada componente de forma independiente. +40% de rapidez en nuevas funcionalidades. 73% de empresas reporta mejora notable de escalabilidad. Hasta 60% de reducción de downtime.

Backend de billing / PL/SQL → Java/.NET: lógica de facturación enterrada en procedimientos Oracle. Entelgy la documenta con IA, la migra a servicios independientes y genera tests automáticos. Al bajar la carga de la BD se puede reducir la licencia Oracle — ahorro significativo en contratos de renovación.

Antes de escribir una línea de código, la funcionalidad queda especificada formalmente y firmada. El código se desarrolla guiado por tests. Cada línea queda trazada a un requisito — trazabilidad total.

Para telco: los sistemas BSS/OSS tienen ciclos de vida muy largos y equipos que rotan. Sin spec, el conocimiento vive en las personas — cuando se van, el conocimiento se va con ellas. Con Spec-Driven, el conocimiento queda en el código y en la documentación, propiedad de la telco.

Para NIS2: las telcos son operadores de infraestructura esencial de comunicaciones bajo NIS2. NIS2 exige documentación técnica y planes de gestión de riesgos sobre los sistemas críticos. Spec-Driven la genera de forma nativa.

Reverse spec: sobre código BSS/OSS legacy existente — reconstruye la spec a partir del código que ya existe, extrayendo el conocimiento del sistema y poniéndolo en un documento propiedad de la telco. Base para la modernización progresiva.

UCE: sprint de 10 días hábiles con un senior. ~42 Story Points entregados y aceptados, tests ≥80%, Spec Compliance 100%. Facturación por capacidad entregada, no por horas.
