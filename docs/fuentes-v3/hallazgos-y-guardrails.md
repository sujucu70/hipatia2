# Hallazgos y guardrails

## Qué conviene conservar de Hipatia2

- La tarjeta de entrada: convierte información dispersa en un contexto de conversación.
- La claridad de los mensajes y una interfaz que ayuda a decidir rápido.
- El criterio de referencias citables y la intención de aportar pruebas.
- La separación entre contenido interno y material apto para cliente.
- El bucle de feedback y la actualización de contenidos como parte del producto.

## Qué conviene mejorar

| Observación | Decisión para Hipatia |
|---|---|
| El recorrido empieza por práctica y avanza de forma lineal. | Empezar por la tarea comercial urgente y permitir entrar después en la práctica. |
| La acreditación antecede a herramientas útiles. | Hacerla opcional e integrada; nunca bloquear la preparación de una reunión. |
| La visión del agente tiene demasiado peso frente a la utilidad comprobable. | Limitar la primera versión a ayudas predeterminadas, transparentes y editables. |
| El repositorio es una etapa independiente. | Recomendar activos dentro de la oportunidad; mantener el repositorio como fondo consultable. |
| Capacidades predictivas futuras son muy visibles. | Reservarlas para una fase posterior, después de validar confianza, contenido y uso repetido. |
| Se sugieren datos de cuenta y autodiagnóstico. | En el demostrador, usar sólo escenarios ficticios y diseñar gobierno de datos antes de cualquier piloto real. |

## Guardrails de confianza

### Etiquetado del contenido

No presentar hipótesis ni borradores como hechos. El usuario debe poder identificar al instante:

- la fuente de un hecho;
- qué información es inferida;
- qué parte es un borrador generado para editar;
- qué pregunta debe validar en la conversación.

### Datos y privacidad

El demostrador no recoge ni transfiere datos de cuentas, contactos o oportunidades reales. Antes de una integración futura se deben acordar, como mínimo:

- finalidad y base de uso de cada fuente de datos;
- responsabilidades de calidad, actualización y acceso;
- tratamiento de datos personales y consentimiento cuando corresponda;
- registro de qué información alimenta una recomendación;
- mecanismo para corregir, ocultar o retirar información.

### Contenido para cliente

La etiqueta «sale al cliente» debe aparecer de forma explícita en cada pieza. Las referencias, logos, casos, cifras y afirmaciones reguladas se validan antes de recomendarse externamente.

### Regulación y mensajes de mercado

No se debe usar una afirmación regulatoria, de cumplimiento o de mercado como argumento comercial sin una fuente primaria vigente y una revisión del responsable correspondiente. Hipatia puede conservar la fuente y la fecha de verificación; no debe sustituir la revisión experta.

## Criterio para avanzar a una fase conectada

CRM, fuentes externas, automatización o autodiagnóstico sólo se plantean cuando se hayan validado:

1. utilidad repetida para comerciales;
2. gobierno editorial de los contenidos;
3. seguridad y reglas de datos;
4. responsables que mantengan activos y recomendaciones;
5. una forma verificable de diferenciar hechos, hipótesis y recomendaciones.
